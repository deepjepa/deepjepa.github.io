# DeepJEPA project website

This repository hosts the project page for **DeepJEPA: Scaling World Models from Within**.

- [Project website](https://deepjepa.github.io/)
- [Paper](https://arxiv.org/pdf/2610.00368)
- [Code repository](https://github.com/deepjepa/DeepJEPA)

The site presents the paper's method, main quantitative results, interaction-aligned computation analysis, and citation information. It is served through GitHub Pages from `index.html`.

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
